# Per Elena ❤️

Sito romantico statico dedicato a Elena.

## Pubblicazione

Il sito è composto da `index.html`, `styles.css` e `script.js` e non richiede build o installazione. Per pubblicarlo con GitHub Pages:

1. Vai in **Settings → Pages**.
2. In **Build and deployment**, scegli **Deploy from a branch**.
3. Seleziona `main` e la cartella `/ (root)`.
4. Salva e attendi la pubblicazione.

Le immagini di sfondo attuali sono immagini dimostrative remote: puoi sostituirle in `index.html` con i nomi delle tue foto, ad esempio `foto1.jpg`, dopo averle caricate nella root del repository.
